# Banking Management System

## Week 1 Mini Project

A simple banking application using Python list storage.

## Features

- Create Account
- Deposit Money
- Withdraw Money
- Balance Check
- Duplicate Account ID Prevention
- Display Accounts

## Storage

Uses Python List as temporary storage.

Note:
Data will be lost after program restart because no database/file storage is used.

## Technologies

- Python 3
- Lists
- Functions
- Loops
